# Apage 前端设计文档（UI/UX 最终方案）

> 内部文档 | 版本：v0.1 | 创建：2026-07-19
>
> 关联：product-design.md §5（功能设计）、roadmap.md Phase 1/4/6
>
> 定位：product-design.md 回答了「做什么、怎么实现」，本文档回答「长什么样、怎么动、怎么上手」。
> 目标一句话：**UI 简洁好看，交互优秀** —— 让用户第一次打开就觉得「这个浏览器是认真做的」。

---

## 一、现状评估：设计里缺什么

product-design.md 在架构、隐私、风险层面已经足够成熟，但前端层存在系统性空白：

| 缺失项 | 后果 |
|--------|------|
| 无设计系统（颜色/字体/间距/圆角/动效令牌） | 各窗口各写各的，视觉不统一，后期返工 |
| 窗口外壳（标签条/地址栏/工具栏）完全未设计 | 浏览器 90% 的交互发生在这一层，恰恰是空白 |
| 控件状态未定义（hover/pressed/disabled/focus/loading/empty/error） | 默认 WPF 样式外露，「半成品感」的来源 |
| 新标签页只有 ASCII 草图 | 这是唯一的首发差异化视觉面，需要像素级规范 |
| 暗黑模式只覆盖网页，未覆盖应用外壳 | 外壳亮色 + 页面暗色 = 刺眼割裂 |
| 无动效规范 | 要么零动效（死板），要么随手乱加（卡顿） |
| 无首次运行体验（onboarding） | 新用户 30 秒内决定留不留 |
| 无错误页/空状态设计 | 断网、无书签、无历史时「裸奔」 |

**结论：架构文档可以直接进入开发，但 UI 必须先有本文档这套规范，否则 Phase 1 写出来的壳会在 Phase 6 全部推倒重来。**

---

## 二、设计原则

1. **内容为主角** —— 外壳 UI 退后一步。工具栏无多余按钮，默认 4 个动作（菜单、下载、脚本、隐私盾），其余收进菜单。
2. **一个强调色** —— 全应用只有一个 accent color，用于焦点、选中、主按钮、隐私统计高亮。克制即高级。
3. **圆角与留白呼吸感** —— 4px 网格，控件圆角 6-8px，搜索框全圆角。宁可空，不可挤。
4. **动效必须有理由** —— 只给三类动效：状态反馈（hover/press）、空间关系（标签开合）、数值变化（拦截计数）。全部 ≤360ms。
5. **默认即正确** —— 零设置开箱即用；设置项能少则少，每个开关都要有存在理由（与产品文档隐私原则一致）。
6. **轻量即美学** —— 不引入重型 UI 库。手写一套 ResourceDictionary 样式（<100KB），守住 <5MB。

## 三、渲染策略（关键架构决策）

| UI 层 | 技术 | 理由 |
|-------|------|------|
| **窗口外壳**（标签条、地址栏、工具栏、菜单、设置、管理器） | WPF + 手写样式 | 原生性能、DPI 清晰、系统集成（标题栏/任务栏/通知） |
| **新标签页** | **本地 HTML/CSS/JS**，经 `SetVirtualHostNameToFolderMapping` 映射到 `apage.newtab` | 产品文档 5.1 已暗示 `backdrop-filter: blur`；毛玻璃、渐变遮罩、count-up 动画、壁纸响应式裁切，CSS 半天的工作量 WPF 要做一周；与 WebMessage 桥天然打通，隐私统计直接从 C# 取数 |
| **网页错误页**（断网/DNS 失败） | 本地 HTML（同上映射） | 与浏览器观感一致，可放「重试」按钮直接调 `location.reload()` |
| **首次运行欢迎页** | 本地 HTML（新标签页变体） | 同上 |

> 新标签页 HTML 资源（含字体子集、无图标的纯 CSS）预算 **<200KB**，打进单文件 EXE 的嵌入资源，运行时解压到 `data/webui/`。不加载任何远程资源，与零网络原则一致。

## 四、设计令牌（Design Tokens）

所有 WPF 样式与 NTP CSS 共用同一份数值，WPF 侧放 `Themes/Tokens.xaml`，NTP 侧放 `tokens.css`（CSS 变量），**数值必须一一对应，禁止各自魔改**。

### 4.2 字体

```
族：Segoe UI Variable / Microsoft YaHei UI（中英文系统自动回落，不打包字体）
--text-xs:   11px   辅助说明、角标
--text-sm:   12px   标签页标题、卡片副文本

--text-md:   15px   区块标题

--clock:     56px / font-weight:200  新标签页时钟（细字重大字号才高级）
```

### 4.3 间距 / 圆角 / 阴影 / 动效

```
间距（4px 网格）：4 / 8 / 12 / 16 / 24 / 32 / 48
圆角：--r-sm 4px · --r-md 8px · --r-lg 12px · --r-pill 999px（搜索框/按钮胶囊）
阴影：只有两级 ——
  --shadow-1: 0 1px 3px rgba(0,0,0,.08)        /* 卡片 */
  --shadow-2: 0 8px 24px rgba(0,0,0,.16)       /* 下拉/对话框/Toast */
动效：
  --dur-fast: 100ms   hover 变色
  --dur-med:  200ms   开合、滑入
  --dur-slow: 320ms   页面级过渡
  --ease:     cubic-bezier(.2,.8,.3,1)   /* 先快后稳，禁止线性 */
  尊重系统「减少动画」设置：开启时全部降级为即时切换
```

## 五、窗口外壳（交互密度最高的层）

### 5.1 整体布局

```
┌──────────────────────────────────────────────────────┐
│ ▤ 标签一      ▤ 标签二(当前)      ▤ +            ─ ▢ ✕ │  ← 标签条 36px
│ ← → ⟳ │ 🔒 example.com ────────── │ 🛡 ⬇ 📜 ⋯      │  ← 工具栏 44px
├──────────────────────────────────────────────────────┤
│                                                      │
│                    网页内容区                          │
│                                                      │
└──────────────────────────────────────────────────────┘
```

- **高度**：标签条 36px + 工具栏 44px = 80px 外壳，比 Chrome (~104px) 更省，呼应「轻量」定位。
- **窗口控制按钮**（最小化/最大化/关闭）融入标签条右端，复用系统视觉但统一圆角 hover 样式；关闭按钮 hover 红 `#E81123`。
- **自定义标题栏**（WindowChrome）：标签条可拖动窗口；双击空白处最大化/还原。
- **无状态栏**。链接悬停 URL 预览用左下角浮层（悬停淡入 100ms，离开淡出），不占常驻高度。

### 5.2 标签条

| 项 | 规范 |
|----|------|
| 标签宽度 | 200px 等分，标签过多时收缩，最小 96px；再多余出左右滚动按钮（不堆叠成两层） |
| 内容 | favicon 16px + 标题（省略号截断）+ 关闭 ✕（默认隐藏，hover 或当前标签才显示 12px 圆钮） |
| 当前标签 | `--bg-surface` 底色 + 顶部 2px accent 指示条，与工具栏无缝衔接（圆角只在顶部两角 8px） |
| 非当前标签 | 透明底，hover 出 `--bg-hover` 圆角块 |
| 加载中 | favicon 位置替换为 12px 环形进度（accent 色，旋转动画） |
| 音频中 | 标题前加 🔊 图标，点击图标直接静音（不必右键） |
| 隐私标签 | 整标签淡紫色调 `rgba(139,92,246,.10)` + 左侧盾图标，一眼可辨 |
| 新建按钮 + | 固定在最右，hover 旋转 90° 变成强调色（100ms，小细节提升质感） |
| 交互 | 中键关闭；拖拽重排（拖动时标签半透明 0.7 跟随，插入位置显示 2px accent 竖线）；双击空白新建标签 |

### 5.3 地址栏（Omnibox）

- **形态**：全圆角胶囊（高 30px，`--r-pill`），默认 `--bg-hover` 底；聚焦时白底 + 2px accent 外圈，并轻微放大到 32px（120ms，过渡平滑不生硬）。
- **左侧状态图标**：https 🔒 / http ⚠ / 新标签页 🔍；点击展开站点信息小卡（Cookie 数、权限、清除站点数据）。
- **右侧**：当前页命中广告拦截时显示 🛡 角标（本页已拦截 N），点击看明细。
- **下拉建议**（聚焦或输入时）：
  - 宽度与地址栏对齐，圆角 12px + `--shadow-2`，最大 8 条。
  - 分组顺序：**书签 → 历史 → 搜索建议**（搜索建议默认关，开启后显示）。每组前 3 条，组间 1px 分隔线。
  - 每行：favicon/图标 16px + 标题 + 灰色 URL；↑↓ 选择（选中行 `--accent-soft` 底），Enter 打开，Tab 补全，Esc 收起。
  - 首条永远显示「搜索：{关键词}」，避免用户不知道按 Enter 会去搜索还是导航。

### 5.4 工具栏按钮

| 按钮 | 行为 |
|------|------|
| 🛡 隐私盾 | 点击弹出隐私面板：本站拦截数、三方 Cookie 拦截数、各开关（拦截/三方 Cookie/WebRTC 防护）按站点临时放行 |
| ⬇ 下载 | 有进行中下载时出进度环；点击出最近 5 条下载浮层 + 「全部」进入管理页 |
| 📜 脚本 | 当前页命中脚本时显示角标 N；点击列出本页生效脚本（可临时停用）+ 打开脚本管理器 |
| ⋯ 菜单 | 书签、历史、下载、设置、新隐私标签、页内查找、关于 |

按钮统一 32×32、圆角 8、hover `--bg-hover`、按下 `--bg-pressed`、图标 16px 线性风格（SVG 内嵌，禁用 Emoji 字体渲染以保证一致性）。

### 5.5 右键菜单 / Toast / 对话框

- 右键菜单：圆角 8、`--shadow-2`、项高 28px、图标列对齐；禁用项 `--text-tertiary`。
- Toast：顶部居中浮出（下滑 200ms），2.5s 自动消失；成功带 ✓、错误带 ✕，不堆叠（新 Toast 替换旧的）。
- 对话框：模态居中、圆角 12、遮罩 `rgba(0,0,0,.32)`；危险操作（删除脚本/清空数据）主按钮用 `--danger` 且需二次确认。

## 六、新标签页（首发视觉差异化，重点打磨）

### 6.1 布局

```
┌─────────────────────────────────────────────────────┐
│                                     [⚙] [🖼]         │ ← 右上角图标，hover 才显现
│                                                     │
│                                                     │
│                  14:32                              │ ← 56px 细字重
│              7月19日 星期六                           │ ← 14px，60% 透明度
│                                                     │
│         ┌─────────────────────────┐                 │
│         │  🔍  搜索或输入网址        │                 │ ← 480px 毛玻璃胶囊
│         └─────────────────────────┘                 │
│                                                     │
│      ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐          │
│      │ G │ │GH │ │ B │ │知 │ │ + │ │   │          │ ← 快捷方式 64px 圆角块
│      └───┘ └───┘ └───┘ └───┘ └───┘ └───┘          │
│                                                     │
│   🛡 本周已拦截 1,283 条追踪 · 342 个广告             │ ← 隐私统计卡
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 6.2 关键规范

- **可读性层（最重要，常被忽略）**：壁纸之上、内容之下垫一层「上透明 → 下 40% 黑」的纵向渐变 + 内容区径向 20% 暗化。任何壁纸（含纯白/纯花）下文字都清晰。文字一律白色 + `text-shadow: 0 1px 8px rgba(0,0,0,.4)`。
- **搜索框**：480×44px，全圆角，`backdrop-filter: blur(20px) saturate(1.4)` + `background: rgba(255,255,255,.18)` + 1px 白边 30% 透明。聚焦时背景升至 85% 白、文字转深色（从玻璃态变为输入态，功能与美感统一）。
- **快捷方式**：64×64 圆角 16 玻璃块 + 站内首字母或 favicon；每行最多 6 个，两行封顶。hover 上浮 2px + 阴影加深（150ms）。「+」块虚线边框。支持拖拽排序、右键编辑/删除。
- **隐私统计卡片**：单行玻璃条，盾图标绿色呼吸微光（2s 循环，透明度 0.6→1）；数字打开页面时 **count-up**（0→1,283，800ms，`ease-out`）。点击进入「隐私报告」页（周趋势迷你柱状图，纯 CSS 绘制）。这是记忆点，数字必须大、必须动。
- **时钟**：先渲染骨架（透明占位）再淡入（300ms），避免打开瞬间「0:00」闪烁。
- **搜索引擎切换**：搜索框内左侧小图标，点击循环切换（百度→必应→Google），带 200ms 翻转动画。
- **壁纸设置**：右下 🖼 按钮 → 底部滑出面板（内置精选 6 张缩略图 + 「选择本地图片」+ 拖入即设）。设置时先 50% 缩放预览 + 「应用/取消」，避免误操作整页突变。
- **进入动画**：页面打开时内容整体透明度 0→1 + 上移 8px（320ms，`--ease`），壁纸 1.05→1.0 缓慢缩放（600ms）。只做一次，不做循环装饰动画。

### 6.3 响应式

窗口宽度 <720px 时：快捷方式收为 4 个/行；时钟缩到 40px；统计卡片折行。最小窗口 640×480 不溢出、不出现横向滚动条。

## 七、其余界面规范

### 7.1 设置窗口（760×560，左侧导航 + 右侧内容）

- 左导航 200px：常规 / 隐私与安全 / 广告拦截 / 新标签页 / 脚本 / 关于。选中项 `--accent-soft` 底 + 左侧 3px accent 条。
- 每个设置项一行：左侧标题 + 灰色一行说明，右侧开关（Toggle，48×26 胶囊，accent 色）。
- **凡是会产生网络请求的开关，说明文字里必须明说**（与产品文档透明原则一致），例：「启动时自动更新规则 —— 开启后每次启动会产生一次后台请求」。
- 关于页：版本号、网络请求清单（完整列出，可审计）、开源许可、检查更新按钮（手动）。

### 7.2 书签 / 历史 / 下载管理器

三者统一为「标签内页」样式（不做独立小窗口）：顶部标题 + 搜索框 + 列表。
- 书签：文件夹树（左 180px）+ 卡片列表（右），支持拖入文件夹、Chrome/Edge HTML 导入按钮放显著位置（换浏览器第一道门槛）。
- 历史：按日期分组（今天/昨天/更早），右侧「清空」按钮红色、二次确认。
- 下载：文件名 + 进度条 + 速度；完成项显示「打开文件 / 打开所在文件夹」。
- **空状态必须有设计**：居中插画占位（单个 48px 线性图标 + 一句文案 + 一个引导按钮），例：书签空 → 「还没有书签，Ctrl+D 收藏当前页」。

### 7.3 脚本管理器（沿用 script-manager.md §6 布局，做视觉升级）

- 列表卡片：左侧 2px 状态条（启用绿 / 禁用灰）替代 🟢⚪ Emoji；启停用 Toggle 开关直接内联在卡片右上，不必点进编辑页。
- 「权限」以胶囊标签展示（`GM_addStyle` → 「修改页面样式」中文释义 + 原文小字），普通用户看得懂。
- 安装确认对话框（§7.2 草图）：权限列表按危险度排序，`GM_xmlhttpRequest`/`GM_setClipboard` 标 ⚠ 黄色提示。
- 编辑器（v0.1 TextBox 基础版）：等宽字体 Consolas 13px、行号栏浅灰底、Tab=4 空格、Ctrl+S 保存（底部 toast「已保存」）。

### 7.4 错误页与首次运行

- **断网/DNS 错误页**：本地 HTML，居中 64px 线性图标 + 「无法打开此页面」+ 一句人话原因（「网络连接似乎断开了」）+ accent 色「重试」按钮。不显示 `ERR_NAME_NOT_RESOLVED` 裸错误码（放小字灰显供排查）。
- **首次运行**：第一次启动新标签页显示欢迎卡（不强制流程）：一句话定位「一个页面，干净打开」+ 两个可选项（设为默认浏览器 / 从 Chrome 导入书签）+ 「开始使用」。不超过一屏，不做人格化多步引导。

## 八、主题与暗色

- 应用外壳三模式：**跟随系统（默认）/ 浅色 / 深色**，切换即时生效（200ms 颜色过渡，不闪白）。
- 深色主题与网页暗黑模式（product-design §5.5 Smart 模式）联动：外壳深色时自动给网页加 `color-scheme: dark`。
- NTP 壁纸场景天然适配：玻璃控件在深色壁纸上自动协调，无需换色。

## 九、可访问性（最低线）

- 所有交互元素键盘可达，焦点环 2px accent 外发光（`:focus-visible`，鼠标点击不出焦点环）。
- 文本对比度 ≥ 4.5:1（令牌默认值已满足，自定义主题时校验）。
- 动效尊重系统「减少动画」设置。
- PerMonitorV2（roadmap 已有）+ 界面元素在 150%/200% DPI 下不虚化（图标用矢量）。
- 界面语言：v0.1 中文优先，文案集中放资源文件，为 v0.2 英文留口。

## 十、WPF 实现要点（防止「设计好看做不出来」）

1. **样式组织**：`Themes/Tokens.xaml`（令牌）+ `Themes/Controls.xaml`（Button/Toggle/ScrollBar/ContextMenu/ToolTip 重模板）+ `Themes/Light.xaml`/`Dark.xaml`（色值）。所有控件 `BasedOn` 这套，禁止内联颜色。
2. **性能红线**：WPF 层禁用 `DropShadowEffect`（GPU 杀手），阴影用 `Border` 模拟或 9-patch PNG；列表一律虚拟化；动画只动 `RenderTransform`/`Opacity`（走 Composition 线程），禁止动 `Width/Margin` 触发布局。
3. **WebView2 背景**：初始化完成前把 `DefaultBackgroundColor` 设为 `--bg-window`，消除白闪。
4. **NTP 加载**：HTML 内嵌关键 CSS（首屏无 FOUC）；统计数据经 WebMessage 取（复用 script-bridge 通道模式，channel: `ntp`）。
5. **图标体系**：内嵌 SVG Path 一套 24 个以内（导航/盾牌/下载/脚本/菜单/设置/壁纸/关闭/搜索/锁等），`StreamGeometry` 存资源字典，不用第三方图标库（体积 + 风格统一）。
